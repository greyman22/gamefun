# Original Game Fun surface artwork

All PNG artwork in this folder is original procedural artwork generated by `tools/generate_materials.py`. No third-party images are used.

Each surface is 256x256 pixels. The plain PNG holds colour and optional cutout alpha; `_detail.png` packs height in red and roughness in green; `_normal.png` is a tangent-space normal map for standard materials. `manifest.json` maps each voxel kind to side/top/bottom surfaces. `icon_*.png` images are isometric projections of the same textures.

The runtime assembles a shared, cached atlas with eight-pixel extruded gutters and mipmaps. Chunk meshes use derivative-based bump shading, so they do not need extra tangent vertices or geometry. Held and dropped objects use shared standard materials and normal maps.

Rebuild with Python, Pillow and NumPy: `python tools/generate_materials.py`. A local `.texture-tools` directory is supported and ignored by Git.
